What you can do

01

Per-key colours

Click, Shift-click or drag to select keys. Pick a colour, or switch them off. The rest of the keyboard stays as it is.

02

Saved presets

Start with WASD Only, Neon Split or Aurora. Save your own presets and apply them from the app or Windows tray.

03

USB and 2.4 GHz

Use USB, or link the tested keyboard and its paired dongle to control colours and presets without the cable.

Dongle control is experimental · supported firmware only
04

App updates

Read the release notes, download an update and restart when you’re ready. Your saved presets and dongle link are kept.

Before you download

Check your model and firmware

Tested on one Crush 80 Pro hardware and firmware combination. The model name alone does not confirm compatibility.

Wrong-model firmware can brick your keyboard.

Custom firmware is only for the same tested Crush 80 Pro hardware and firmware revision. Other Crush 80 variants and Pro revisions are not validated. This app does not include or install firmware.

Stock firmware
Whole-board VIA lighting and USB key mapping. No arbitrary per-key RGB or app-controlled rear-color sync.
Per-key & rear lights
Requires the exact tested combined v1.04 firmware, CRC 0x5566DDF2, and its expected PKRG v2 capabilities. Settings → Firmware setup checks compatibility.
Wireless
Picker and presets through the locally linked 320F:5088 receiver are experimental. Bluetooth RGB control is not implemented. Do not re-pair a linked receiver to another board.
Battery
Shows Windows' Bluetooth battery report when available. Old readings say “last known.” It is not live dongle battery or charging telemetry.

Setup and everyday use

Why does Windows show an unknown publisher?

This beta does not yet have a Windows Authenticode certificate. Download only from this project's GitHub Releases. The app uses its own release signatures to verify later updates; these do not replace Windows signing or remove SmartScreen warnings.

Will a lighting preset stay after power-off?

Your named preset is saved on the PC. Per-key colors are live keyboard memory and reset when the keyboard loses power, so apply the saved preset again. Clear Keys turns off the main keys; the rear feet and heartbeat are separate. The heartbeat/status animation keeps its native behavior.

Can I use SignalRGB at the same time?

Quit SignalRGB and other keyboard controllers before using Crush Control's direct lighting controls. The installed app blocks direct RGB writes while it detects SignalRGB running. Its separate SignalRGB plugin provides whole-board color, not per-key streaming.

How do app updates work?

Install this updater-enabled version manually the first time. Later, Settings → App updates lets you check, read release notes, download and choose Restart and install. Checks do not automatically download or install. Presets and linked-receiver settings use the same PC profile. App updates never flash the keyboard.

Where can I find the source code?

The app source is on GitHub. Original app code uses the MIT licence. Included patch and validation tools retain GPL-2.0-only terms, and third-party components keep their own licences. The repository starts with the beta.9 development snapshot; the download above is still beta.8. No keyboard firmware is included.

Is this an official WOBKEY app?

No. Crush Control is an independent project by mi0ir, without endorsement from WOBKEY. This is experimental evaluation software, not a general compatibility or recovery guarantee. No firmware is distributed here.
